# UI Mockups

These HTML mockups are the screens that Ford approved in the Annotator Initial Setup plan, revision 4.
The documentation pass puts them next to the real screens.

- Run `python3 design/mockups/build.py` and `python3 design/mockups/keys.py` to rebuild `out/`.
- Run `design/mockups/render.sh` to render `out/*.html` to `design/mockups/images/*.png` at 2x.
- `root.css` holds the design-system tokens for the frame and captions. App colors come from the Scrawl source.
